PARTIE 1 — بالعربية
--------------------------------------------------------------------------------

1) ما هذا البرنامج؟
--------------------------------------------------------------------------------
برنامج لإدارة موظفين في المؤسسة/الإدارة، يعمل **بدون إنترنت** وكل البيانات
تُحفظ محلياً على جهازك فقط (لا خادم، لا اشتراك، تكلفة الاستعمال = 0 دولار).

المكوّنات:
  • قائمة الموظفين (بحث، تصفية، إضافة، تعديل، أرشفة).
  • بطاقة كل موظف: المعلومات، سجل الوضعيات، الرخص، المداومة.
  • المداومة اليومية: تدخل، ربط بالموظف، حذف.
  • الرخص: جارية / قادمة / منتهية مع معاينة حساب فورية.
  • لوحة القيادة: أرقام اليوم وتنبيهات (رخص تنتهي، موظفون يعودون…).
  • استيراد ملفات CSV (موظفون / مداومة) مع معاينة قبل التسجيل.
  • نسخ احتياطي مشفّر (AES-256) واستعادة.
  • قفل برمز سري (PIN) وبصمة مع قفل تلقائي.
  • واجهة عربية RTL افتراضياً + واجهة فرنسية.

2) التثبيت — أندرويد (APK)
--------------------------------------------------------------------------------
  1. انسخ الملف  ADMIN_STAFF_v1.0.0.apk  إلى هاتفك/لوحيتك.
  2. انقر عليه، وقد يطلب النظام «تثبيت من مصادر غير معروفة» → اضغط **سماح**.
  3. افتح التطبيق من أيقونة «admin_staff».
  ملاحظة: التطبيق موقّع بمفتاح التثبيت (debug key) → التثبيت مباشر بلا مشاكل.

3) التشغيل — نسخة ويندوز
--------------------------------------------------------------------------------
  على جهاز Windows 10/11 افتح المجلد  build\windows\x64\runner\Release
  وانقر على  admin_staff.exe
  (لا يحتاج تثبيتاً — يعمل مباشرة، البيانات تُحفظ في مجلد المستخدم).

4) شاشات البرنامج (الشريط السفلي — 5 تبويبات)
--------------------------------------------------------------------------------
  📊 لوحة القيادة (الرئيسية)
     - أرقام: عدد الموظفين، الأرشيف، مداومة اليوم، الرخص المنتهية اليوم.
     - تنبيهات: رخص تنتهي اليوم / غداً / خلال 3 أيام، موظفون يعودون اليوم،
       مداومة غير مرتبطة بموظف.
     - أزرار سريعة: استيراد، إضافة موظف، إضافة مداومة، إضافة رخصة.
     - اسحب للأسفل لإعادة التحديث.

  👥 الموظفون
     - اكتب في خانة البحث: اسم (عربي/فرنسي)، رقم matricule، الهاتف، PPR.
     - زر الفلتر (أعلى اليمين): القسم، الدرجة، الوضعية، إظهار المعطّلين.
     - زر ➕ (أسفل) لإضافة موظف جديد.
     - ✎ بجانب أي اسم لتعديل بيانات الموظف.
     - ⌫ داخل التعديل لإيداع الموظف في الأرشيف (لا يُحذف نهائي أبداً).
     - النقر على اسم الموظف يفتح بطاقته.

  📇 بطاقة الموظف (4 تبويبات)
     - المعلومات: كل بيانات الموظف + زر تعديل ✎.
     - الوضعيات: السجل الحالي والسابق + «إضافة وضعية» (نوع + تاريخ بداية
       + تاريخ نهاية اختياري + ملاحظة). النهاية الفارغة = وضعية مفتوحة.
     - الرخص: قائمة رخص الموظف + إلغاء رخصة.
     - المداومة: آخر سجلات المداومة الخاصة بالموظف.

  🗓️ المداومة
     - ← / → للتنقل بين الأيام، وزر «اليوم» للرجوع لليوم الحالي.
     - ➕ إضافة سجل: التاريخ + matricule (يُقترح الموظف أثناء الكتابة) +
       الفترة + بداية/نهاية + hpad.
     - 🔗 بجانب أي سجل غير مربوط: اضغط لربطه بموظف (مطابقة بالاسم/matricule).
     - 🗑 لحذف سجل بعد تأكيد.

  🏖️ الرخص
     - ثلاثة أقسام: جارية | قادمة | منتهية + بحث حر.
     - ➕ إضافة رخصة:
         نوع الرخصة ← التاريخ ← ابحث عن الموظف (matricule/الاسم) ← حفظ.
         تظهر **معاينة فورية**: تاريخ النهاية المحسوب + تاريخ العودة + المدة.
       إذا ظهرت «تنبيهات تعارض» (رخصة أو وضعية متداخلة) يمنحك البرنامج
       خيار «حفظ على أي حال» — القرار بيدك دائماً.
     - عند إلغاء رخصة يبقى السجل في القائمة مشطوباً (تاريخ كامل محفوظ).

  ⚙️ الإعدادات
     - اللغة: العربية / Français (تُحفظ فوراً).
     - الأمان:
         • تفعيل/تغيير/إلغاء رمز الدخول (4 إلى 6 أرقام).
         • البصمة (إذا كان الجهاز يدعمها).
         • القفل التلقائي: بعد 1 / 5 / 15 دقيقة خلفية التطبيق.
     - البيانات:
         • تصدير الموظفين CSV (اختر المجلد → employees_YYYY-MM-DD.csv).
         • المراجع: إضافة/تعطيل الأقسام والدرجات والوظائف.
     - النسخ الاحتياطي:
         • إنشاء: اختر مجلداً + اختر كلمة سر → ملف  *.asbk  مشفّر.
         • استعادة: اختر ملف النسخة + كلمة السر → **تُستبدل كل البيانات**
           بعد تأكيد صريح.
         ⚠︎ إذا نسيت كلمة سر النسخة الاحتياطية لا يمكن فتحها — احتفظ بها.

5) استيراد ملفات CSV (خطوات)
--------------------------------------------------------------------------------
  1. من تبويب الموظفون أو لوحة القيادة اضغط «استيراد».
  2. اختر النوع: موظفون / مداومة.
  3. اضغط «اختر ملف» وحدّد ملف .csv
  4. تظهر **المعاينة**: عدد الصفوف، الجديد، المحدّث، المكرر، الصفوف المرفوضة
     مع سبب كل رفض، وجدول مطابقة الأعمدة.
  5. «تأكيد الاستيراد» → يُسجَّل كل شيء في عملية واحدة (أو ينجح كله أو
     يرجع كل شيء كما كان — بلا نصف بيانات).

  أسمدة الأعمدة المقبولة (لا فرق بين كبير/صغير):

  ملف الموظفين (employees):
      matricule            ← إلزامي (رقم التأجير)
      nom_ar, prenom_ar    ← الاسم بالعربية (أحدهما إلزامي)
      nom_fr, prenom_fr    ← الاسم بالفرنسية
      section              ← القسم (يُنشأ تلقائياً إذا لم يكن موجوداً)
      fonction             ← الوظيفة
      grade                ← الدرجة
      qualite              ← الصفة
      ppr                  ← رقم PPR
      telephone_mobile     ← الهاتف
      statut               ← الوضعية الحالية
      date_entree          ← تاريخ الالتحاق (YYYY-MM-DD)

  ملف المداومة (permanence):
      date                 ← إلزامي (YYYY-MM-DD)
      matricule            ← لربط السجل بالموظف (اختياري)
      permanencier         ← اسم المداوم
      section, grade       ← القسم والدرجة
      hpad                 ← رقم HPAD
      telephone_mobile     ← الهاتف
      horaire              ← الفترة مثال: 08:00 - 16:00

  اضغط زر ✕ داخل التصحيح لإزالة تعيين عمود، أو اختر عموداً من القائمة.

6) قواعد الرخص — مهم
--------------------------------------------------------------------------------
  كل المدد (عدد الأيام/الساعات، بداية العدّ، نهاية الأسبوع، العطل الرسمية)
  تُؤخذ **من جدول بيانات البذرة** داخل البرنامج: الإعدادات ← الأقسام ←
  أنواع الرخص. لا رقم مكتوب داخل الكود.

7) حل المشاكل الشائعة
--------------------------------------------------------------------------------
  • فتح البرنامج ببطء أول مرة: طبيعي (يجهّز قاعدة البيانات).
  • لا تظهر نتائج بحث: تأكد من تفعيل «إظهار المعطّلين» في الفلتر.
  • رفض استيراد: اقرأ سبب الصف في قائمة الصفوف المرفوضة —
    غالباً matricule ناقص أو تاريخ بصيغة غير YYYY-MM-DD.
  • التطبيق يطلب الرمز عند العودة: القفل التلقائي مفعّل (غيّره من الأمان).
  • تغيير لغة الجهاز لا يغيّر اللغة: اختر اللغة يدوياً من الإعدادات.
  • نسيت رمز الدخول: من الإعدادات ألغِ الرمز وأنشئ رمزاً جديداً
    (إن كان القفل مفعّلاً افتح الإعدادات أولاً قبل تفعيله).
  • الرجوع للاستعادة: الإعدادات ← النسخ الاحتياطي ← استعادة.

--------------------------------------------------------------------------------
PARTIE 2 — FRANÇAIS
--------------------------------------------------------------------------------

1) Présentation
--------------------------------------------------------------------------------
Application de gestion du personnel, 100 % hors ligne, données stockées
uniquement sur votre appareil (aucun serveur, coût total = 0 $).

Onglets : Tableau de bord | Employés | Permanences | Congés | Paramètres.

2) Installation
--------------------------------------------------------------------------------
  Android  : installez  ADMIN_STAFF_v1.0.0.apk  (autorisez « sources inconnues »).
  Windows  : lancez  build\windows\x64\runner\Release\admin_staff.exe
             (aucune installation requise).

3) Fonctionnalités principales
--------------------------------------------------------------------------------
  • Employés : recherche par nom (AR/FR), matricule, téléphone, PPR ;
    filtres section / grade / statut ; création, modification, archivage
    (jamais de suppression définitive).
  • Fiche employé : informations, historique des statuts, congés, permanences.
  • Permanences : navigation jour par jour, création, liaison à un employé
    (🔗), suppression.
  • Congés : onglets En cours / À venir / Terminés, aperçu instantané
    (fin calculée, retour, durée), détection des conflits avec choix final.
  • Import CSV : aperçu complet (nouveaux, mis à jour, doublons, lignes
    rejetées avec motif) puis validation en une seule transaction.
  • Sauvegarde chiffrée AES-256 + restauration (fichier *.asbk).
  • Sécurité : code PIN (4-6 chiffres), biométrie, verrouillage automatique
    (1 / 5 / 15 minutes).
  • Langue : arabe (RTL, par défaut) ou français.

4) Colonnes CSV acceptées
--------------------------------------------------------------------------------
  Employés : matricule (obligatoire), nom_ar, prenom_ar, nom_fr, prenom_fr,
             section, fonction, grade, qualite, ppr, telephone_mobile,
             statut, date_entree.
  Permanence : date (obligatoire, AAAA-MM-JJ), matricule, permanencier,
             section, grade, hpad, telephone_mobile, horaire.
  Les valeurs ne sont pas sensibles à la casse ; les sections/grades/fonctions
  inconnus sont créés automatiquement.

5) Problèmes courants
--------------------------------------------------------------------------------
  • Aucun résultat : activez « Afficher les inactifs » dans le filtre.
  • Import refusé : lisez le motif sur chaque ligne rejetée.
  • Verrouillage automatique : Paramètres → Sécurité.
  • Mot de passe de sauvegarde perdu = sauvegarde illisible : conservez-le.
